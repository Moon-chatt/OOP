# Повербанк – Практична робота (Lab-1): Класи, об'єкти

**Дисципліна:** Об'єктно-орієнтоване програмування  
**Виконала:** Ляшенко К.В., група 621п, освітня програма 121 «Інженерія програмного забезпечення»

## Опис

Предметна область – повербанк (портативний акумулятор). Реалізовано:

- клас `Powerbank` (повербанк): модель, ємність, заряд, дата виробництва, стан (перелік `PowerbankState`);
- методи поведінки: заряджання, віддача заряду, вмикання/вимикання, оцінка часу роботи;
- до N об'єктів (N задає користувач, 1–100);
- перевірка всіх значень, що вводить користувач.

## Вимоги

- [.NET SDK 10](https://dotnet.microsoft.com/download)
- Visual Studio 2022/2026 (необов'язково, можна `dotnet` CLI)

## Запуск

```bash
git clone https://github.com/<ваш-логін>/OOP_Lab1_Liashenko.git
cd OOP_Lab1_Liashenko
dotnet run --project OOP_Lab1_Liashenko
```

Або відкрийте `OOP_Lab1_Liashenko.slnx` у Visual Studio і натисніть **Ctrl+F5**.

## Меню програми

| Пункт | Дія |
|---|---|
| 1 | Додати об'єкт |
| 2 | Переглянути всі об'єкти |
| 3 | Знайти об'єкт |
| 4 | Продемонструвати поведінку |
| 5 | Видалити об'єкт |
| 0 | Вийти з програми |

На початку програма запитує N – максимальну кількість об'єктів (1–100).
