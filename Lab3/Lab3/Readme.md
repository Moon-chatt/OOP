# Повербанк – Практична робота (Lab-3): Конструктори, перевантаження (overloading)

**Дисципліна:** Об'єктно-орієнтоване програмування  
**Виконала:** Ляшенко К.В., група 621п, освітня програма 121 «Інженерія програмного забезпечення»

## Опис

Предметна область – повербанк (портативний акумулятор). Реалізовано:

- чотири перевантажені конструктори (в т.ч. без параметрів та з викликом `this(...)`);
- властивість `ConstructorInfo` – який конструктор спрацював;
- перевантажені методи `Charge` та `EstimateRuntime`;
- при автоматичному додаванні конструктор обирається випадково.

## Вимоги

- [.NET SDK 10](https://dotnet.microsoft.com/download)
- Visual Studio 2022/2026 (необов'язково, можна `dotnet` CLI)

## Запуск

```bash
git clone https://github.com/<ваш-логін>/OOP_Lab3_Liashenko.git
cd OOP_Lab3_Liashenko
dotnet run --project OOP_Lab3_Liashenko
```

Або відкрийте `OOP_Lab3_Liashenko.slnx` у Visual Studio і натисніть **Ctrl+F5**.

## Меню програми

| Пункт | Дія |
|---|---|
| 1 | Додати об'єкт |
| 2 | Переглянути всі об'єкти |
| 3 | Знайти об'єкт |
| 4 | Продемонструвати поведінку |
| 5 | Видалити об'єкт |
| 0 | Вийти з програми |

На початку програма запитує N – максимальну кількість об'єктів (1–100).
