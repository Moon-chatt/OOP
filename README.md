Робота	Тема	Репозиторій

Lab-2	Інкапсуляція, властивості	OOP_Lab2_Liashenko
Lab-3	Конструктори, перевантаження (overloading)	OOP_Lab3_Liashenko
Lab-4	Статичні поля, властивості, методи	OOP_Lab4_Liashenko
Lab-5	Модульне тестування (unit testing)	OOP_Lab5_Liashenko
Lab-6	Generics. Collections	OOP_Lab6_Liashenko
Lab-7	Серіалізація / десеріалізація	OOP_Lab7_Liashenko
Загальні вимоги
.NET SDK 10
Visual Studio 2022/2026 або dotnet CLI
Запуск будь-якої роботи
dotnet run --project OOP_LabN_Liashenko
Для Lab-5, Lab-6, Lab-7 тести запускаються командою dotnet test.
